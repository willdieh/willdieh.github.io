## UI Data Bindings

Now that we have a somewhat familiar looking application window, thanks to our MenuBar, let's see how we can display data on the screen. 

### Template Defaults

Recall that the WinUI3 template default application already includes function stubs for an `int32_t` object they call `MyProperty`. It's interesting that they don't actually create a member variable to hold the value, only these stub functions. 

It's important to point out that these two functions represent `getter`/`setter` functions. C++ does not have such a paradigm (typically, you just access the member variable directly). Instead, we see this kind of thing in languages like C# and Java. 

Because the cross-abi access between XAML and C++ must also work with other languages, the design requires this getter/setter setup. As a result, we **must** make the corresponding functions in order for XAML to access the underlying variable.

**`MainWindow.xaml.h`**
```C++
// Getter/Setter functions
int32_t MyProperty();
void MyProperty(int32_t value);
```

 If we look at the function definitions, we see they only throw an exception because they're not yet implemented

**`MainWindow.xaml.cpp`**
```C++
int32_t MainWindow::MyProperty()
{
    throw hresult_not_implemented();
}

void MainWindow::MyProperty(int32_t /* value */)
{
    throw hresult_not_implemented();
}
```

Finally, if we look at the `idl` file, we see the cross-abi definition for this `MyProperty` object so it can be accessed in both XAML and C++. Here we see it defined as an `Int32`.

**`MainWindow.idl`***
```idl
namespace WinUIApp
{
    [default_interface]
    runtimeclass MainWindow : Microsoft.UI.Xaml.Window
    {
        MainWindow();
        Int32 MyProperty;
    }
}
```

### Our First Effort

The first thing we need to do is create a local variable to hold this `int32_t` value. Easy enough - just add one to the MainWindow struct. We'll mark it as `private` since we use the getter/setter functions to access it. 

**`MainWindow.xaml.h`**
```C++
    struct MainWindow : MainWindowT<MainWindow>
    {
        ...

    private:
      int32_t m_MyProperty = 0;
    };
```

**`MainWindow.xaml.cpp`**
```C++
    int32_t MainWindow::MyProperty()
    {
        return m_MyProperty;
    }

    void MainWindow::MyProperty(int32_t value)
    {
        m_MyProperty = value;
    }
```

Next we need a XAML object to display our variable in the UI. 

Currently, we have a `<Grid>` layout with the `<MenuBar>` in Row 0. Let's just add a `<TextBlock>` to Row 1 and we display our `Int32` there. We use the `x:Bind` attribute to specify the name of the object as defined in the `idl` file (and in our c++ code).

**`MainWindow.xaml`**
```xaml
<Window
    ...
    <Grid>
        <Grid.RowDefinitions>
            <RowDefinition Height="Auto"/>
            <RowDefinition Height="*"/>
        </Grid.RowDefinitions>
        <MenuBar Grid.Row="0">
            ...
        </MenuBar>
        <TextBlock Grid.Row="1" Text="{x:Bind MyProperty}"/>
    </Grid>
</Window>
```

Recompile and you should now see the `Int32`'s current value `0` just under the MenuBar.
