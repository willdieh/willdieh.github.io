## Observable Bindings

In XAML and winrt, an *observable* binding is one that reflects changes in the UI whenever the underlying value is modified in code. 

Let's update our MenuBar click-handler functions to set a different value for `m_MyProperty` whenever we change the layout in the View menu

**`MainWindow.xaml.cpp`**
```c++
...
using namespace winrt::Microsoft::UI::Xaml::Controls;   // For RadioMenuFlyoutItem
...
void MainWindow::OnOrientationClick(IInspectable const& sender, RoutedEventArgs const& e)
{
    // Cast the sender parameter as a RadioMenuFlyoutItem
    auto clickedItem = sender.as<RadioMenuFlyoutItem>();

    // If Cast was successful, check which radio button was clicked
    if (clickedItem)
    {
        if (clickedItem.Text() == L"Portrait")
        {
            m_MyProperty = 1;
        }
        else if (clickedItem.Text() == L"Landscape")
        {
            m_MyProperty = 2;
        }
    }
}
```

If you compile and run the app, you notice there's no change when we toggle the layout in the menu. This is because the simple binding we did in the last post for the `Int32 MyProperty` object was ***not*** observable - the GUI will always display the initial value. So how do we make `MyProperty` *observable*?
